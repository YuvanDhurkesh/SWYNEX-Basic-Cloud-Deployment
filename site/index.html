    How this page reached you

    1. Your browser requests the site over HTTPS.
    2. Amazon CloudFront serves it from the nearest edge location, or fetches it from the origin on a cache miss.
    3. Origin Access Control signs that fetch, so only this distribution can read the bucket.
    4. Amazon S3 holds the files in a private bucket in ap-south-1 (Mumbai), with all public access blocked.
